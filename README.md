<h1 align="center">DeskZones</h1>

<p align="center"><b>바탕화면 정리에 자신 없는 분, 아이콘이 너무 많아 정리할 엄두가 안 나는 분들을 위한 프로그램입니다.</b></p>

- 바탕화면 아이콘을 종류별(3D설계, 개발·IT도구, 오피스·업무, 게임 …) <b>펜스(구역)</b>로 자동으로 나눠 정리합니다.
- 파일은 절대 옮기지 않고 **아이콘 위치만** 바꿉니다.
- 마음에 들지 않으면 언제든 **설치 전 배치로 되돌릴 수** 있습니다.

### 이런 분께 추천합니다

- 바탕화면이 아이콘으로 꽉 찬 분
- 매번 아이콘 찾느라 헤매는 분
- 정리해도 금방 어질러지는 분
- 모니터 여러 대에서 아이콘 위치가 자꾸 흐트러지는 분

## 받기

[Releases](https://github.com/ciaondev/deskzones/releases)에서 최신 `DeskZones-Setup-<버전>.exe`를 받아 실행하세요.

- Windows 10/11, 관리자 권한 없이 설치됩니다 (`%LOCALAPPDATA%\Programs\DeskZones`).
- 서명이 없는 프로그램이라 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
- 설치 없이 쓰려면 `DeskZones-<버전>-portable.zip`을 풀고 안의 `DeskZones.exe`를 실행합니다.
- 받은 파일은 같은 릴리스의 `SHA256SUMS-<버전>.txt`로 확인할 수 있습니다.

## 쓰는 법

1. 설치하면 작업 표시줄 오른쪽 트레이에 아이콘이 생깁니다. **설치만으로는 아이콘이 움직이지 않습니다.**
2. 트레이 아이콘 → **바탕화면 정리 (미리보기)** 에서 분류와 배치를 확인하고 **정리 적용**을 누르면 정리됩니다.
3. 분류가 틀린 아이콘은 미리보기에서 바꾸거나 다른 펜스로 끌어 놓으면 기억합니다 (같은 프로그램의 새 버전에도 적용).

## 되돌리기

- **마지막 복원·정리 되돌리기**: 바로 전 배치로 돌아갑니다.
- **설치 전 배치로 되돌리기…**: 처음 실행할 때(아무것도 옮기기 전) 저장해 둔 배치로 돌아가고 펜스를 끕니다.
- 프로그램을 제거할 때도 "바탕화면 아이콘을 설치 전 배치로 되돌릴까요?"라고 묻습니다.

## 미분류 제보와 개인정보

분류가 안 된 프로그램을 개발자에게 알려 주면 분류 규칙(`rules.json`)을 늘리는 데 씁니다.

- 미리보기나 "분류 규칙…" 창의 **미분류 제보…** 를 누를 때만 보냅니다. 보낼 내용을 표와 JSON으로 먼저 보여 주고, 줄마다 빼고 보낼 수 있습니다.
- **보내는 것**: 프로그램 바로 가기의 이름, 제품명, 회사명, 실행 파일 이름, 자동 분류 결과와 사용자가 고른 분류, 앱·규칙 버전, 설치마다 임의로 만든 번호(이름·PC와 무관).
- **보내지 않는 것**: 파일 경로, 사용자·PC 이름, 이메일 주소, 문서·사진·폴더 이름.

## 자동 업데이트

- **분류 규칙**: 하루 한 번 이 저장소의 `rules.json`을 확인해 더 새 버전만 받습니다. 아이콘은 움직이지 않고 다음 미리보기부터 적용됩니다.
- **새 버전 알림**: 하루 한 번 `latest.json`을 확인해 알려 줍니다. "받기"를 누르면 설치 파일의 SHA256을 확인한 뒤 설치 화면을 엽니다. 몰래 설치하지 않습니다.
- 둘 다 설정에서 끌 수 있습니다.

## 이 저장소

- `rules.json`: 분류 규칙 (키워드, 회사, 파일 종류, 게임 런처 등). 버전이 올라가면 앱이 받아 씁니다.
- `latest.json`: 최신 버전 정보 (버전, 설치 파일 주소, SHA256, 변경 내용).
